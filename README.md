This project uses CNN models and its ensemble to classify the severity of Knee OsteoArthritis in the X-ray images.

CNN Models used:
-InceptionV3
-MobileNetV2
-ResNet101
-Xception

DO:
Create an environment and install the necessary dependencies.
Download the dataset from the Link.txt inside /Dataset
Inside the ZIP File extract only the /kneeKL224 folder for training
